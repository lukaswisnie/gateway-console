AI Gateway Console

Sign the repository's CI in to the AI gateway and check that it stays signed in.

1 · Connect

Needs a GitHub token with access to the repository (a full-access personal or fine-grained token works). Sent only to api.github.com — kept in this tab, or on this device if you tick "remember".

2 · CI sign-in

Starts the sign-in for CI. When the approval link appears, open it and approve with the account CI should act on behalf of (a dedicated account, not a personal one). Everything else, credentials included, is handled for you — nothing to copy.

3 · Health

Regular automatic checks that the CI sign-in still works. A check also runs automatically after every sign-in, so a fresh sign-in is always verified.
