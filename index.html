Claude Gateway Console

Sign the repository's CI in to the Claude apps gateway and watch its health — a thin GUI over the Gateway — Sign-in and Gateway — Health GitHub Actions workflows.

1 · Connect

Needs a GitHub token with access to the repository: Actions read/write, Checks read, Secrets read (a classic PAT with repo scope also works). The token stays in this browser tab (session storage) and is sent only to api.github.com.

2 · CI sign-in

Starts the device login on a GitHub runner. When the approval link appears, open it and approve with the Google account CI should be attributed to (a dedicated one, not a personal). The workflow stores the GW_REFRESH_TOKEN and GW_CERT_PIN secrets itself — nothing to copy.

3 · Gateway health

The daily check that the CI sign-in, the certificate pin and the pinned models still work.
